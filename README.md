# LeadFlow

A simple B2B lead and outreach management platform built as a full-stack SaaS project.

LeadFlow helps users manage business leads, organize outreach campaigns, and prioritize prospects using an intelligent lead scoring system.

## Features

- User registration and JWT authentication
- Create, edit, delete and search leads
- Lead status and scoring
- Campaign management
- Dashboard with basic lead analytics
- REST APIs
- MySQL database

## Tech Stack

**Frontend:** React, TypeScript, Vite, Tailwind CSS  
**Backend:** Node.js, Express, TypeScript  
**Database:** MySQL, Prisma  
**Authentication:** JWT, bcrypt
